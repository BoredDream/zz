# 第三问模型：含日内预报更新的多阶段随机购电策略

本文件固定第三问所采用的模型。实现见 `src/q3_multistage.py`，全年回测与产物生成见
`scripts/export_q3_multistage.py`、`scripts/build_result3_multistage.mjs`，
独立验收见 `scripts/validate_q3_multistage.py`。

替代关系：本模型取代原先的"共同储能轨迹"滚动 SAA/MPC 模型（`src/q3_solver.py`，
结果保留在 `outputs/q3/` 供对照）。旧模型主结算口径把初始计划费记为沉没成本，
本模型改用题面口径，两者对下调时段的结果不同，不能混算。

## 1. 时间网格

采用双时间框。计划/调整购电保留**模板行框**，与附件5模板列标签一一对应：

| 记号 | 含义 |
|---|---|
| `t = 0..143` | 第 `t` 个时段覆盖 `[(t+1)·10min, (t+2)·10min)` |
| `t = 0` | 0:10–0:20 |
| `t = 143` | 次日 0:00–0:10 |

模板每行是当天0:00发布、覆盖当日00:10至次日00:10的同一版计划。实际执行、SOC、
紧急购电和总费用按自然日00:00–24:00跨行重组：自然日第0段取前一计划行末列，
其余143段取当日计划行前143列。表2统一为0:00–4:00至20:00–24:00。

0:00优化窗口为145段：`h=0`是前一日已锁定的00:00–00:10，`h=1..144`是当天新发布计划。
阶段0最晚只使用`d-2`的完整145维历史残差；`d-1`模板行在0:00尚未完整实现，不得入样本。

四个预报发布时刻（附件3）：

| 阶段 `m` | 发布时刻 | 起始时段 `TSTAGE[m]` | 该阶段可调整区间 |
|---|---|---|---|
| 0 | 0:00 | 0 | 制定全天计划 `x[0..143]` |
| 1 | 6:00 | 35 | `[35, 71)` |
| 2 | 12:00 | 71 | `[71, 107)` |
| 3 | 18:00 | 107 | `[107, 144)` |

（6:00 对应时段起点 `(35+1)×10 = 360min`，故 `t₁ = 35`，其余同理。）

## 2. 储能物理口径

与 README「固定口径」第 6 条及问题 1/2 完全一致：

- 充电量 `c_t`、放电量 `g_t` **均定义在交流母线侧**（kWh）；
- SOC 递推 `S_t = S_{t-1} + η·c_t − g_t/η`，`η = 0.9`；
- 充、放电单时段上限同为 `CMAX = 5000 × (1/6) = 833.3333` kWh（母线侧）；
- `S ∈ [1200, 10800]` kWh，初值 6000 kWh。

注意放电一个 `CMAX` 会消耗 `CMAX/η = 925.93` kWh 的储电量。

## 3. 费用函数

题面原文："计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50%；
调整购电量高于计划购电量的部分，超出部分的电价是交易时刻电价的 1.5 倍。"

单时段费用（`x` = 0:00 计划量，`q` = 最终生效合约量，`z` = 紧急购电量）：

```
C_t = p_t·min(x_t, q_t) + 1.5·p_t·(q_t − x_t)⁺ + 0.5·p_t·(x_t − q_t)⁺ + 5·p_t·z_t
```

关于 `q` 分段线性凸（斜率 `0.5p` / `1.5p`），可用 `q + 0.5|q−x|` 的形式无整数变量地线性化：

```
C_t = 0.5·p_t·x_t + 0.5·p_t·q_t + p_t·(q_t − x_t)⁺ + 5·p_t·z_t
```

两式恒等（对 `q ≥ x` 与 `q < x` 分别验证）。LP 里直接用后者。

报表口径按前式拆成题面点名的两个成分（`settle_parts()`）：

| 填表列 | 取值 |
|---|---|
| 计划购电量·全天购电费 | `Σ p_t·min(x_t, q_t)` |
| 调整购电量·全天购电费 | `Σ [1.5·p_t·(q_t−x_t)⁺ + 0.5·p_t·(x_t−q_t)⁺]` |
| 紧急购电量 | 各紧急时段合并后的 `Σ z_t`，费用 `Σ 5·p_t·z_t` |

三者之和恒等于模型总费用，验收脚本按日逐条核对。

## 4. 决策结构与非预期性

每个阶段解一个两阶段随机 LP：

- **第一阶段（锁定）**：`m = 0` 时是全天计划 `x[0..143]`；`m ≥ 1` 时是 `[t_m, t_{m+1})` 的
  生效合约量 `D_t`（即最终 `q_t`）。
- **第二阶段（逐情景 recourse）**：`[t_{t+1}, 144)` 上仍可再调的合约量 `Q^k`、
  储能 `c^k, g^k`、紧急购电 `z^k`、弃电 `w^k`、SOC `S^k`。

非预期性体现在：锁定段只有一个变量、不吃情景下标；未来段才逐情景分叉。
这样"未来还能再调"的期权价值被正确定价，不会让 `m` 阶段的决策偷看 `m+1` 阶段的预报。

每个情景的约束：

```
功率平衡  Qeff_t + z_t + g_t − c_t − w_t = L_t − G_t        （四项均母线侧）
SOC 递推  S_t − S_{t-1} − η·c_t + g_t/η = 0,   S_{-1} = S_cur
偏差线性化 U_t ≥ Q_t − x_t,  U_t ≥ 0        （m ≥ 1 的锁定段用 U_t ≥ D_t − x_ref_t）
界        0 ≤ c, g ≤ CMAX,  1200 ≤ S ≤ 10800,  其余变量 ≥ 0
```

目标函数系数（`K` 个情景等权）：

- 锁定段：`0.5·p_t`（`m = 0` 且 `t < t_next` 时为 `p_t`）或超计划罚 `p_t`；
- recourse 段：`0.5·p_t/K` 与 `p_t/K`；
- 紧急购电：`α·p_t/K`，`α = 5`；
- 末端储能水价：末时段 SOC 记 `−λ/K`，`λ = 0.478` 元/kWh（≈ 谷价 0.43 / η）。

求解器：`scipy.optimize.linprog(method='highs')`，稀疏 `csr_matrix` 组装。

## 5. 预测子模型

**光伏**：附件3 的整点预报经 PCHIP 保形插值到 10 分钟序列，以发布时刻实测出力作锚点
（避免日出/日落段插值悬空与负值），只对 `t ≥ t_m` 的时段生效。
另设一路独立预测源——近 10 日指数衰减加权均值（`λ=0.8`）。两源误差近似不相关，
按阶段权重 `WCOMB = [0.4, 0.6, 0.9, 0.4]` 组合，白天 RMSE 由 543 kW 降至 355 kW（0:00 发布）。

**负载**：近 3 个同星期日均值 × 近 7 日水平偏差修正；日内更新时用已实现时段的
实际/预测比对剩余时段整体缩放，阻尼后限幅到 `[0.85, 1.15]`。

## 6. 场景生成

对阶段 `m`，取过去 `K` 天的**整条** 144 维预测残差路径叠加到当日预测上
（`scenarios()`），而不是逐点独立抽样——整条路径重采样才能保住误差的时序相关性。
默认 `K = 30`，跳过 `dd < 10` 的样本。

## 7. 实时层

合约量锁定后，10 分钟粒度的唯一自由度是"放电 vs 紧急购电"（或"充电 vs 弃电"）。
紧急电价恒为 `5·p_t`，故贪心接近最优：

```
净缺 net = L_t − G_t − q_t > 0:
    g = min(net, CMAX, (S − SMIN)·η);  S −= g/η;  z = net − g
净余 s = −net > 0:
    c = min(s, CMAX, (SMAX − S)/η);    S += η·c;  w = s − c
```

实测：改用"按计划 SOC 设预留下限"反而更差，因为该下限建立在偏乐观的光伏预报上。

## 11. 已知局限

- 名为多阶段，实为"滚动两阶段"：每个阶段把其余未来折叠成一个两阶段 recourse，
  不宣称严格多阶段随机最优。
- 实时层为贪心规则，非滚动 LP 最优；`docs/_bench_lp.py` 的基准显示滚动 LP
  在全年规模下耗时不可接受。
- 场景取自历史残差重采样，未做同月/同形态分层，尾部风险可能被低估。
- 储能末端价值取常数水价 `λ`，未做终端 SOC 与次日的耦合求解。
