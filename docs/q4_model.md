# 第四问模型：波动电价下的购电策略

本文件固定第四问所采用的模型。实现见 `src/q4_solver.py`，全年回测与产物生成见
`scripts/export_q4.py`、`scripts/build_result4.mjs`，独立验收见 `scripts/validate_q4.py`。

第四问要求"在波动电价下重新计算问题2和问题3"，故有两个变体，共用同一套模型：

| 变体 | 对应 | 决策结构 | 输出 |
|---|---|---|---|
| 4-2 | 问题2 | 只在 0:00 决策一次，`q ≡ x`，不设调整机制 | `result4-2.xlsx`（3 张表） |
| 4-3 | 问题3 | 0:00 计划 + 6/12/18 点三次滚动调整 | `result4-3.xlsx`（4 张表） |

`src/q4_solver.py` 从 `src/q3_multistage.py` 复用时间网格、储能口径、实时层与结算口径，
只替换电价相关的部分。因此本文件只写与第三问**不同**的地方；未提及处一律与
`docs/q3_multistage_model.md` 相同。

## 1. 沿用的固定口径

以下三条与问题 1/2/3 完全一致（见 README「固定口径」及 `docs/q3_multistage_model.md`）：

- **时间**：模板行框，第 `t` 个时段覆盖 `[(t+1)·10, (t+2)·10)` 分钟，
  `t=0` → 0:10–0:20，`t=143` → 次日 0:00–0:10；
- **储能**：充/放电量均定义在**交流母线侧**，`S_t = S_{t-1} + η·c_t − g_t/η`，
  单时段充放电上限同为 `CMAX = 5000·DT = 833.3333` kWh（母线侧）；
- **结算**：`C_t = p_t·min(x_t,q_t) + 1.5·p_t·(q_t−x_t)⁺ + 0.5·p_t·(x_t−q_t)⁺ + 5·p_t·z_t`。

唯一的差别是 `p_t` 的口径：问题 1/2/3 用附件1 的确定分时电价，第四问用附件4 的
实际波动电价 `PMAT[d,t]`（365×144，0.0076–1.7936 元/kWh，均值 0.7662）。
**结算一律按当日实际电价**，预测值只参与决策、不参与结算。

## 2. 与第三问的三点本质差别

1. **0:00 时当天电价未知**，必须先建电价预测模型；6/12/18 点可用已实现电价滚动修正。
   （第三问的光伏预报由附件3 直接给出，第四问没有电价预报可用。）
2. **违约价/紧急价都定义为"交易时刻电价"的倍数**，所以相对价格结构不变，
   第三问的费用线性化式 `C_t = 0.5·p_t·x_t + 0.5·p_t·q_t + p_t·(q_t−x_t)⁺ + 5·p_t·z_t`
   原样成立，不需要改写 LP。
3. **目标里出现 `E[p·q]`**。同一阶段的 here-and-now 决策不带场景下标，其系数必须取
   期望电价；而 recourse 变量 `q^k, z^k` 与价格同场景配对，用 `p^k`。
   ⇒ 报童条件从概率分位数变成**价格加权分位数**。

## 3. 电价预测子模型

两因子结构 `p̂ = 形态 × 水平 × 日内 AR(1) 修正`：

| 因子 | 取法 | 依据 |
|---|---|---|
| 形态 | 近 `WIN=20` 天逐时段均值归一化 | 附件4 日内形态很稳定：谷 22:00–05:00≈0.42，峰 19:00≈1.35，午间凹陷 11:00≈0.47 |
| 水平 | `0.5×前一日均价 + 0.5×窗口均价` | 日均价滞后 1 天相关 0.506 |
| 日内修正 | `m ≥ 1` 时用已实现段 `[0, t_m)` 估水平比 `lvl` 与瞬时偏离 `dev`，按 `PHI^k` 衰减外推 | 10 分钟滞后自相关 0.96（1 步）/ 0.85（3 步）/ 0.35（12 步） |

`lvl` 为近 18 个时段（3 小时）的实际/预测均值比，截断到 `[0.6, 1.6]`；
`dev` 为末时段残差比，截断到 `[0.5, 2.0]`。`PHI = 0.85` 由多步外推误差最小化标定
（单步自相关虽是 0.96，但直接用它外推反而更差）。

**实测误差**（2025 年留出预热 30 天后）：

| 阶段 | 发布时刻 | MAPE | MAE (元/kWh) | 同一窗口下 0:00 版 MAE | 前一日持续 MAE |
|---|---|---:|---:|---:|---:|
| 0 | 0:00 | 13.2% | 0.0799 | 0.0799（同） | 0.0846 |
| 1 | 6:00 | 9.1% | 0.0556 | 0.0916 | 0.0950 |
| 2 | 12:00 | 11.6% | 0.0837 | 0.0865 | 0.0892 |
| 3 | 18:00 | 13.4% | 0.0832 | 0.0631 | 0.0651 |

> 各阶段 MAPE **不可直接横比**：剩余窗口不同、窗口内时段构成也不同（阶段 3 只剩
> 晚高峰，本身波动最大）。可比的是"同一窗口下含更新 vs 不含更新"（第 4、5 列）。
> 该对照显示：`m=1` 更新收益显著（−39%），`m=2` 基本持平（−3%），
> **`m=3` 反而变差（+32%）**——见第 10 节「已知局限」第 3 条。

## 4. 场景生成

对阶段 `m` 取过去 `K` 天（跳过 `dd < 10`）的**同日配对**残差，三类量一起重采样以保住相关性：

```
负载  L^k = max(L̂_t + (L_{d-j,t} − L̂_{d-j,t}), 0)
光伏  G^k = max(Ĝ_t + (G_{d-j,t} − Ĝ_{d-j,t}), 0)
电价  p^k = max(p̂_t · clip(PMAT[d-j,t] / p̂_{d-j,t}, 0.3, 3.0), 1e-3)
```

电价用**乘性**残差（价格非负，加性残差会出现负价），并截断到 `[0.3, 3.0]` 倍。
默认 `K = 30`。

## 5. 目标函数与"价格加权分位数"

单时段把 `q` 从 `x` 抬高一单位：边际成本是 `0.5·E[p]`（`0.5p·q` 那一项恒付），
边际收益是当 `q > x` 时省下的 `p`。故一阶条件为

```
E[ p · 1{q > x} ] = 0.5 · E[p]
```

即**用价格加权的超出概率**等于 0.5，是报童分位数规则在随机价格下的推广：
概率按价格大小加权，贵时段的"缺货"更值得避免。

LP 中不显式写这个条件，而是把 `E[p]`（here-and-now 系数）与 `p^k`（recourse 系数）
按上述结构填进目标函数，由求解器一次算出。系数明细：

- `m = 0` 锁定段：`t < t_next` 用 `p̂_t`（决策即最终合约），`t ≥ t_next` 用 `0.5·p̂_t`；
- `m ≥ 1` 锁定段：`0.5·p̂_t`，另有超计划罚项 `p̂_t`；
- recourse 段：`0.5·p^k_t / K` 与 `p^k_t / K`；
- 紧急购电：`α·p^k_t / K`，`α = 5`；
- 末端水价：`λ = water_value(p̂) = (当日预测最低 12 时段均价)/η`。

## 6. 变体 4-2 的退化

`adjust=False` 时 LP 不设 recourse 购电变量，`tn = T`（后续无分叉），
`q ≡ x`，费用退化为 `p·x + 5·p·z`，与问题 2 在波动电价下的形式完全一致。
验收脚本对此单独断言 `max|q − x| = 0`。

## 7. 参数汇总

| 参数 | 值 | 说明 |
|---|---|---|
| `PHI` | 0.85 | 电价残差 AR(1) 衰减 |
| `WIN` | 20 天 | 形态/水平滚动窗口 |
| `ALPHA` | 5.0 | 紧急购电电价倍数 |
| `K` | 30 | 场景数 |
| `TSTAGE` | [0, 35, 71, 107, 144] | 同第三问 |
| 其余 (`η, SMIN, SMAX, CMAX, λ` 形式) | 同第三问 | 见 `docs/q3_multistage_model.md` |

## 9. 交付期结果（2025-02-01 – 12-31，334 天）

| 项目 | 4-2（对应问题2） | 4-3（对应问题3） |
|---|---:|---:|
| 计划购电费 | 13,567,750.95 元 | 12,718,029.74 元 |
| 调整相关费用 | 0（不设调整机制） | 883,540.76 元 |
| 紧急购电费 | 912,456.77 元 | 222,155.29 元 |
| **总费用** | **14,480,207.73 元** | **13,823,725.79 元** |
| 紧急购电量 | 144,947.50 kWh | 41,355.11 kWh |
| 充电量 / 放电量（母线侧） | 6,075,378.60 / 4,921,366.87 kWh | 6,311,354.22 / 5,112,600.58 kWh |
| 弃电量 | 1,701,320.86 kWh | 1,219,773.54 kWh |
| 上调量 / 下调量 | 0 / 0 | 595,747.48 / 290,727.90 kWh |
| 含紧急购电的日期 | 121 / 334 | 148 / 334 |

**滚动调整（4-3）相对一次决策（4-2）全年省 656,481.94 元（4.5%）**，
紧急购电量由 144,947.50 降到 41,355.11 kWh（−71.5%）。
值得注意的是 4-3 发生紧急购电的**天数反而更多**（148 vs 121）——滚动调整把少数几次
大额紧急购电拆成了更多次的小额紧急购电，而不是简单地消除它。

**与第三问（确定性电价）的对照**：附件1 的分时电价恰是附件4 电价过程的逐时段均值
（逐时段最大差 5.15e-05，属表格取整），故两组结果可干净对比：

| | 第三问（确定性） | 第四问 4-3（波动） | 差 |
|---|---:|---:|---:|
| 总费用 | 13,159,245.19 元 | 13,823,725.79 元 | +5.0% |
| 紧急购电量 | 38,939.67 kWh | 41,355.11 kWh | +6.2% |
| 弃电量 | 1,254,451.26 kWh | 1,219,773.54 kWh | −2.8% |

即：**在期望相同的价格过程下，波动本身使最优费用上升约 5.0%**，这部分是
"信息缺失 + 风险溢价"的代价，与价格预测的不可消除误差直接相关。

## 10. 已知局限

1. 电价预测为两因子（形态×水平）+ 日内 AR(1)，没有用任何外部信息（天气、星期、
   节假日），峰谷时段的系统性偏差只能靠水平比部分吸收。
2. 场景取自历史残差重采样，未做同月/同形态分层，尾部价格风险可能被低估；
   电价残差截断在 `[0.3, 3.0]` 倍，进一步削掉了极端情形。
3. **18:00 的日内更新在预测精度上是负收益，但在费用上几乎中性**。
   `m=3` 用 15:00–18:00（午后低价段）估出的水平比 `lvl`，被乘到 18:00–24:00
   （晚高峰）上，跨了价格形态的"体制"，同一窗口 MAE 由 0.0631 升到 0.0832（+32%）；
   6:00 的更新（−39%）与 12:00 的更新（−3%）都是正的。
   但按**费用**做的消融（`docs/_ablate_q4_m3.py`，2025-06-30 起 60 天，其余设定不变，
   仅把 `m=3` 的预测换成不更新的 0:00 版）显示：
   `2,952,846.68` vs `2,952,921.69` 元，**差 75 元（0.003%）**。
   原因是该阶段只覆盖 `t=107..144`（37 个时段），而调整罚项斜率仅 `0.5p`，
   预测的水平偏差对 `q` 的推动很小。**结论：不必为此改动模型**；
   若要修，应让修正只作用在同体制时段。
4. 与第三问同：名为多阶段实为"滚动两阶段"；实时层为贪心规则而非滚动 LP 最优；
   末端储能价值取常数水价。
