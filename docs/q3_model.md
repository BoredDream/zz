# 第三问模型（修正版）

## 1. 定位与信息边界

采用每6小时重求解的因果滚动样本平均近似（SAA/MPC），不宣称严格多阶段随机最优。每天0:00制定计划，6:00、12:00、18:00仅调整未交付区间。所有预测和残差样本均受发布日期截断；实际值仅在对应时段结束后进入后续决策。

区间采用起点口径。自然日实际量跨行映射，模板一行对应00:10至次日00:00；自然日费用单独按00:00至24:00统计。00:00合同量锁定为前一日最后一次提交的次日午夜量，此项为合同假设。

## 2. 净负荷情景

附件3整点光伏预报以发布时刻前最近一个已观测10分钟值为锚点，分段线性插值到10分钟。负荷中心预测由最近同星期轮廓与最近7日轮廓的稳健中位数加权得到，权重按历史28日MAE选择。

对每个发布时刻分别构造历史残差轮廓，滚动选择7日或14日窗口，形成等权净负荷情景。0:00最晚使用前两日的完整残差；日内发布最晚使用前一日完整残差。

## 3. 共同储能轨迹

同一发布时刻的全部情景共享购电合同量、充电量、放电量和SOC轨迹，只有紧急购电与弃电允许按情景变化：

\[
A_h+D_h+E_h^\omega-C_h-U_h^\omega=N_h^\omega,
\]

\[
S_{h+1}=S_h+0.9C_h-D_h/0.9.
\]

下一发布时刻前的36个10分钟储能动作严格按该共同轨迹执行，不再用事后贪心规则覆盖。实际情景下的紧急购电和弃电由能量缺口直接确定。

## 4. 结算口径

主口径为保守解释：初始计划费用保留；每次提交相对当前生效合同逐笔计费。若本次上调、下调量为 \(Q_h^+,Q_h^-\)，则本次新增费用为

\[
1.5p_hQ_h^++0.5p_hQ_h^-.
\]

每次修改均保存，取消后恢复也会产生两次费用。该合同解释为“需人工确认”。

另计算退款且仅按最终净额结算的敏感性口径：

\[
p_hA_h^{final}+0.5p_h|A_h^{final}-G_h|.
\]

## 5. 策略比较

独立回测日内新预报集合 \(\varnothing,\{6\},\{12\},\{18\},\{6,12\},\{6,18\},\{12,18\},\{6,12,18\}\)，每套策略保持自己的SOC和跨日合同状态。另设“仍在6/12/18重优化但冻结0:00光伏预报”的基线，以分离新预报信息和重优化机会。

零点计划没有建立完整情景树来联合定价未来调整机会，这是剩余的模型近似。
