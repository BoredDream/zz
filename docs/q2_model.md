# 第二问修正模型

## 1. 问题类型与决策时序

第二问采用滚动经验情景随机线性规划。每天0:00确定一版计划购电量；实际净负荷在各10分钟区间到达后，储能按当前SOC作因果补救，仍不足的部分紧急购电。

不使用附件3。预测、残差情景和参数选择只使用计划日前已经完整观测的数据。

## 2. 时间口径

采用区间起点口径。附件2每一原始行依次表示当日00:10至次日00:00。自然日数组按00:00至23:50排列，因此

\[
N_{d,0}=N^{raw}_{d-1,143},\qquad
N_{d,t}=N^{raw}_{d,t-1},\quad t=1,\ldots,143.
\]

2025年1月1日00:00在附件2中缺失，只用附件1净负荷预测作初始化，不进入历史残差校准。2025年2月1日起的交付结果均使用真实跨行午夜值。

模板日期行定义为当天0:00发布的同一版计划，144列覆盖当天00:10至次日00:00。自然日00:00已承诺购电量来自前一日计划的末列；不再用次日重新求解结果拼接当天行。

## 3. 预测与经验情景

中心预测由最近4个同星期日中位数与最近7日中位数加权：

\[
\widehat N_{d,t}(w)=w\,\operatorname{Med}_{j\in W_d}N_{j,t}
+(1-w)\,\operatorname{Med}_{j\in R_d}N_{j,t}.
\]

每天从 \(w\in\{0,0.25,0.5,0.75,1\}\) 中选择过去28个已完成预测日MAE最小者。残差保留为145维整条交付轮廓：

\[
\boldsymbol\varepsilon_j=
(N_{j,0:143},N_{j+1,0})-
(\widehat N_{j,0:143},\widehat N_{j+1,0\mid j}).
\]

计划日 \(d\) 最晚只能使用 \(j=d-2\) 的完整轮廓，因为 \(j=d-1\) 的末端在计划时刻尚未出现。残差窗口在7日和14日中按过去7个完整轮廓的能量评分滚动选择。每条历史残差轮廓等权形成一个情景，保留跨时段相关性及次日午夜提前量差异。

## 4. 直接情景优化

优化窗口含145个区间。第0个区间是当天00:00，购电量 \(g^-_d\) 已由前一日计划锁定；第1至144个区间对应本日新发布的144个计划变量 \(G_{d,k}\)。

情景 \(\omega\) 下设置充电 \(C^\omega_h\)、放电 \(D^\omega_h\)、紧急购电 \(E^\omega_h\)、剩余电量 \(U^\omega_h\) 和SOC \(S^\omega_h\)。目标为

\[
\min\ \sum_{k=1}^{144}p_kG_{d,k}
+\sum_{\omega}\pi_\omega\sum_{h=0}^{144}5p_hE^\omega_h
-v\sum_\omega\pi_\omega S^\omega_{145}
+\epsilon\sum_{\omega,h}\pi_\omega(C^\omega_h+D^\omega_h).
\]

主模型取保守终端价值 \(v=0.9\min_t p_t\)，并对0、1、2倍终端价值进行指定日期敏感性检验。该设置替代未经验证的48小时强制复位条件。

能量平衡为

\[
g^-_d+D^\omega_0+E^\omega_0-C^\omega_0-U^\omega_0=N^\omega_0,
\]

\[
G_{d,h}+D^\omega_h+E^\omega_h-C^\omega_h-U^\omega_h=N^\omega_h,
\quad h=1,\ldots,144.
\]

SOC及物理约束为

\[
S^\omega_{h+1}=S^\omega_h+0.9C^\omega_h-D^\omega_h/0.9,
\]

\[
1200\le S^\omega_h\le10800,
\qquad 0\le C^\omega_h,D^\omega_h\le833.3333,
\]

\[
G_{d,k},E^\omega_h,U^\omega_h\ge0.
\]

## 5. 因果运行补救

情景解的等概率平均充放电作为不依赖未来实际值的参考轨迹。每个实际区间依次执行：

1. 按当前SOC裁剪参考充放电并消除同时充放电；
2. 若供给不足，先取消充电，再增加当前可行放电，最后紧急购电；
3. 若供给富余，先取消放电，再增加当前可行充电，仍有富余则记为剩余电量；
4. 更新SOC后进入下一时段。

该规则仅使用当前实际净负荷、已承诺购电量和当前SOC，不读取未来实际值。

## 6. 输出与对照

- 工作簿计划表按计划发布日期及其144个交付时段统计。
- 报告总费用按2025年2月1日至12月31自然日00:00至24:00统计。
- 无储能基线使用相同历史情景，逐时段直接最小化计划购电费与期望紧急购电费。
- 数值验收包括原始午夜来源、能量平衡、SOC递推、容量、功率、跨日连续、同时充放电及紧急购电同时充电。
