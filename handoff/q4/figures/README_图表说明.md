## 3. 出图时的硬性约束（复述，避免走偏）

- **默认禁止双 Y 轴**（`ax.twinx()`）；量纲不同一律做**上下共享 x 轴**的面板。
- 输出 **SVG + PDF + PNG(600 dpi)** 三格式；`svg.fonttype="none"`、`pdf.fonttype=42`。
- 尺寸：单图 `(7.0, 3.5)`；上下双面板 `(7.0, 4.5)`；左右双面板 `(7.0, 3.3)`。
- `fill_between` 只用于**有数学意义**的区域（分位带／偏差区／约束区），$\alpha=0.08\sim0.18$。
- 一张图**只有一个强调色** `C_ACCENT = "#A9705A"`。
- **不能只靠颜色区分**：两变体必须同时用**线型**（4-3 实线 / 4-2 虚线）或 marker 区分，保证黑白可辨。
- 图内**不放大标题**（标题交给图注）。
- 颜色语义与第二、三问共用同一套常量（`C_MAIN #4C6E91`、`C_GREY #9AA4AE` 等）。
- 绘图脚本 **只读 `_figdata/`**，**不重跑求解器**（4-3 重跑一次要 388.7 秒）。
