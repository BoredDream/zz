## 3. 复现

```powershell
cd handoff/q4/scripts
python gen_plot_data.py          # ① 生成 _figdata（21 个文件，只读仓库产物，不重跑求解器）
python gen_handoff_csvs.py       # ② 生成三个根级 CSV

python figs_q4_paper.py          # ③ 先做 1,226 项数据审计，再出 14 图 × 3 格式
cd ..
python make_album.py             # ④ 装册 -> 图集_第四问_论文版.pdf
```

依赖：`numpy`、`pandas`、`openpyxl`（读附件用）；出图还需 `matplotlib`、`Pillow`。

**注意**：两个脚本都**不重跑求解器**，只读 `outputs/q4/` 的已交付产物；
若要重跑模型本身，见 `docs/q4_model.md` §8（4-3 约 389 秒/次、4-2 约 126 秒/次）。

## 5. 五个必须同时说明的口径（论文下笔前必读）

1. **双时间框**：计划/调整购电用**模板行**（当日 00:10 → 次日 00:10，与附件5 逐列对应）；
   执行、储电量、紧急购电与总费用用**自然日**（00:00–24:00，跨行重组）。**两者不可跨表相加**
   （4-2 计划量差 174.7709 kWh、4-3 差 905.0417 kWh）。
2. **结算只用实际电价**：附件4 的实际电价；**预测值只参与决策、不参与结算**。
3. **模型定位**：两变体名为多阶段、实为**滚动两阶段**，**不宣称严格多阶段随机最优**；
   实时层是贪心规则（4-3 按锁定轨迹执行），不是滚动 LP 最优。
4. **不做"唯一最优策略"的表述**：LP 普遍退化——跨算法**最优值**最大相对差仅 1.011e-08，
   但 **44.6% 的 (LP, 算法) 对给出不同的最优解向量**，逐时段最大差达数千 kWh。
   年度**费用**稳定，逐时段充放电安排只是**最优解之一**。
5. **两变体不是"同一个模型多跑几次调整"**：情景数（4-2 逐日 7 或 14，4-3 固定 30）、
   电价预测器（4-2 无日内 AR(1) 修正）、终端水价（0.33417 vs 0.478 元/kWh）都不同。
   **4-2 还完全不用附件3**，4-3 沿用第三问的附件3 光伏预报链路。
