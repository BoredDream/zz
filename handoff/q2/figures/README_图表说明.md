## 零、优秀论文级视觉规范（9 张图统一执行）

| 项目 | 规范 |
|---|---|
| 背景 | 纯白 |
| 边框 | **去掉顶部与右侧**；左/下边框 0.7 pt、色 #B0B0B0 |
| 网格 | 仅水平，浅灰 #DDDDDD、lw 0.5、alpha 0.35（弱化，不抢数据） |
| 主色 | **科研蓝 #2F6FB0**（计划量、预测值、主序列） |
| 唯一强调色 | **橙色 #D98943**（紧急购电、最大偏差点、主模型档位、关键结论框） |
| 对照/次要 | 灰 #9AA3A8、灰蓝 #91A5B5（低饱和，不与主色抢注意力） |
| 储电量 | 低饱和绿 #6F9B72（**仅图3a、图3b 使用**，全篇不重复用色） |
| 多重区分 | 颜色 **+** 线型 **+** marker：实线/圆点=主序列；虚线/方点=对照或实测；点划线/三角=次要 |
| 黑白可辨识 | 每张图任意两条曲线至少在线型或 marker 上不同；橙色一律最粗实线 |
| 双轴 | **全部取消 twinx**（图2a、图3a 原有双轴已重构），避免双轴尺度误导 |
| 字号 | 刻度 8.5 pt、轴标题 9.5 pt、图例 8.5 pt、面板小标题 9 pt |
| 版面 | A4 双栏 figsize 7.1 × (3.6–4.5) 英寸 |
| 输出 | SVG（矢量、文字可编辑）+ PDF（矢量）+ PNG（**600 dpi**） |

| 图5 | 左栏堆叠柱 + **橙色节省标注**（框+引线+参考连线）；右栏由分组柱改为**折线+marker**，主模型档位橙色实心 | 折线的斜率比柱高更容易看出"2 倍终端价值时费用上升"；橙色注释直接给出核心结论 |

## 三、逐图说明（用途 + 读法 + 关键数字 + 可抄图注）

### 图1 `fig1_netload_forecast`｜净负荷预测与情景包络（2×2）

**用途**：这是第二问唯一的"预测 vs 观测"配对图。它要回答两件事——模型在题目指定的四个日期上
预测得准不准；以及模型内部那组历史残差情景张开多大的不确定性范围。图注承担"全期为留出集回测"的声明。

**读法**：深灰实线=真实观测；蓝实线=模型中心预测；蓝色色带=历史残差情景包络（两层：全距、10–90 分位）。

**关键数字**：四日 MAE 48.43 / 78.28 / 51.92 / 39.17 kWh per 10 min；全期 MAE 61.29、RMSE 85.82。
情景区间 n=14 / 14 / 14 / 7。

**图注**：
> **图 1　2025 年四个指定日期净负荷的模型中心预测与真实观测对比。**
> 数据为 2025-02-01 至 2025-12-31 交付期（334 天 × 144 个 10 分钟时段）的净负荷（小区负载 − 光伏出力，
> 单位 kWh/10 分钟）。本图为**留出集回测**结果：模型在每天 0:00 仅使用此前已完整观测的历史轮廓生成预测，
> 图中所绘预测值与真实观测值均为同期实际数据，**不含任何未来外推区间**，亦无训练期拟合曲线
> （该预测器为滚动中位数加权，无拟合值序列）。深灰实线为真实观测值；蓝实线为本文模型中心预测；
> 蓝色由深至浅的色带为**历史残差情景包络**（n=14 / n=7），**不是置信区间，也不是预测区间**。
> 图内仅作一处标注，规则为"本图所示日期范围内绝对预测偏差最大的时点"（2025-06-21 11:30 前后，
> 311 kWh/10 分钟）。全期预测精度 MAE 61.29、RMSE 85.82 kWh/10 分钟。
> 需说明的是，情景包络偏窄：四日合计仅 68.40% 的真实观测落在情景全距之内、54.51% 落在 10–90 分位之内。

### 图1b `fig1b_typical_day`｜典型日功率曲线与分时电价（上下双面板）

**用途**：交代数据的**日内形态**——这是后面所有调度结论的物理前提。它说明为什么储能套利有空间：

**读法**：上面板三条线（负载/光伏/净负荷），绿色底纹标出"光伏富余"时段（净负荷为负）；
下面板是电价阶梯线，蓝底纹=谷价区、红底纹=尖峰价区。

**关键数字**：负载 3309–5959 kW；光伏峰值 7612 kW 出现在 12:10 前后；
电价 0.3713–1.3952 元/kWh（14:40–14:50 最低、18:50–19:00 附近最高）；
光伏富余 6,248 kWh 集中在 10:00–14:30。

**图注**：
> **图 1b　典型日（附件1）的功率曲线与分时电价。**
> 上图为小区负载、光伏出力与净负荷（负载 − 光伏）的日内变化，绿色底纹区间表示光伏出力超过负载的
> 时段，合计富余电量约 6,248 kWh；下图为分时电价（题面规定每日相同），蓝色底纹为谷价区
> （低于 0.45 元/kWh）、红色底纹为尖峰价区（高于 1.25 元/kWh）。图中数据为附件1 给出的
> 144 个 10 分钟时段的实测统计值，未作任何平滑或插值。

### 图2a `fig2a_single_day_dispatch`｜单日计划购电量与电价（双轴）

**用途**：**回答"模型会不会算账"**。这是最直观的策略图：看购电柱是否在低价时、看它是否在光伏出力时归零、
看它在尖峰价时段是否被压到最低。审阅者一眼就能判断策略是否合理。

**读法**：蓝柱=计划购电量；红柱=紧急购电量（如有）；深灰线=实际净负荷；红色阶梯线=电价（右轴）；
浅红底纹=尖峰价时段（≥1.25 元/kWh）。

**关键数字**（2025-06-21）：全天计划购电 42,769.8742 kWh，紧急购电 0；
09:40–15:00 约 5 小时购电量接近 0（光伏覆盖负载）；
18:00–21:00 尖峰价时段购电被压到最低。

**图注**：
> **图 2a　2025-06-21 计划购电量、实际净负荷与电价的日内关系。**
> 蓝色柱为当日 0:00 发布的计划购电量（144 个 10 分钟时段），深灰线为实际净负荷，红色阶梯线为电价
> （右轴），浅红色底纹为尖峰价时段（电价 ≥1.25 元/kWh）。该日无紧急购电。当日计划购电量合计
> 42,769.87 kWh，全天购电费 26,344.09 元；购电量在光伏出力覆盖负载的正午时段降至接近零，
> 在尖峰价时段被压缩至最低，体现"低价多购、高价少购"的策略特征。

### 图3b `fig3b_soc_hist`｜储电量分布与充放电量分布（左右双面板）

**用途**：**这是全图集里唯一能暴露模型结构性特征的一张**。它回答两个没被文字说清的问题：
储电量是否长期贴边界？充放电是否经常打满 833.33 kWh 的功率上限？
实测结果对"储能容量与功率是否够用"这个改进方向极有说服力。

**读法**：左面板 SOC 分布直方图（红线=上下限）；右面板充放电量直方图（红线=功率上限）。

**关键数字**：贴上限（≥10750 kWh）占 **14.75%**、贴下限（≤1250 kWh）占 **4.21%**；
充放电打满功率上限的比例为充电 **4.1%**、放电仅 **0.2%**；
放电分布明显比充电更集中于低值。

**图注**：
> **图 3b　全期储电量与单时段充放电量的分布。**
> 左图为 48,096 个时段起始储电量的分布，红色虚线为运行上下限 1200 / 10800 kWh，
> 其中贴上限（≥10750 kWh）的时段占 14.75%、贴下限（≤1250 kWh）的占 4.21%；

## 六、字体注意事项（直接影响出图质量）

本机实测：**只有 `Microsoft YaHei` 同时支持中文与 U+2212 减号**。
`SimHei`、`SimSun`、`KaiTi`、`FangSong`、`DengXian`、`Microsoft JhengHei`
**均缺少 U+2212 字形**——若用它们出图，图1、图1b、图4a 的负值坐标
会渲染成**空白方框**。

两脚本已做双保险：① 字体优先级把 `Microsoft YaHei` 排首位；
② 设置 `axes.unicode_minus = False`，用 ASCII 连字符替代 U+2212。

**换机器出图时**，若目标机器没有 Microsoft YaHei，请改用开源的
`Noto Sans CJK SC`（Google Fonts 可下载），并保持 `axes.unicode_minus = False`。
