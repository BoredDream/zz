## 零、视觉规范（全部图件统一执行）

依据《数学建模论文科研绘图指导规范》，落在 `figs_q3_paper.py` 顶部常量区，**改一处即全文生效**。

| 项目 | 规范 |
|---|---|
| 背景 | 纯白；二维；**无 3D / 渐变 / 发光 / 阴影 / 装饰色块** |
| 边框 | **去掉顶部与右侧**；左/下 0.7 pt、色 `#B4BBC2` |
| 网格 | **仅水平**，`#DFE3E7`、lw 0.5、**alpha 0.20**（弱于数据） |
| 主色 | **深蓝灰 `#4C6E91`**（计划量、主数据、本文方法）；深版 `#3A5470` |
| 实测值 | 深灰 `#5B6470` |
| 对照 / 次要 | 灰 `#9AA4AE`、浅灰 `#C9D0D6` |
| **唯一强调色** | **去饱和赤陶 `#A9705A`**——只给风险 / 最大误差 / 紧急购电 / 最差结果 |
| 状态与边界 | 低饱和绿 `#7E9B84`（**仅储电量与约束边界使用**） |
| 多重区分 | 颜色 **+** 线型 **+** 稀疏 marker（`markevery=24`）；黑白打印可辨 |
| 双 Y 轴 | **全部取消 `twinx`**，改上下共享 x 轴面板 |
| 面积填充 | 仅"光伏富余"（净负荷 < 0）等有数学含义区域，`alpha=0.12` |
| 字号 | 刻度 8.5 / 轴标题 9.5 / 图例 8.5 / 子图标题 9 / 注释 7.5 pt |
| 版面 | 单图 7.1×3.5；上下双面板 7.1×4.7；三面板 7.1×5.4 英寸 |
| 单位写法 | `电价 / (元/kWh)`、`电量 / kWh`、`净负荷 / MW`、`时刻 / h` |
| 图例 | `frameon=False`、名称短（≤6 字）、不遮挡数据 |
| 图内文字 | **每图 ≤2 处关键标注**，无大白框、无长弯箭头 |
| 输出 | **SVG**（文字可编辑）+ **PDF**（矢量）+ **PNG（600 dpi）** |

`figs_q3_paper.py` 在绘图**之前**执行 `audit()`，本次运行**通过 2,854 项断言**，包括：

| 审计项 | 断言 | 结果 |
|---|---|---|

| 三项费用 | 计划+调整+紧急 = 总费用（**逐日**核对 334 条） | ✅ |
| 月度一致 | 月度合计 = 全期合计 | ✅ |
| 单位与量级 | 电价 ∈ (0.3, 1.5)；紧急购电费占比 1.6331%；紧急电量占比 0.1918% | ✅ |

**数据纪律（规范第三节原文）**：**严禁**为了让图"看起来正常"而修改真实数据、擅自平滑真实数据、
> 擅自删除异常值、擅自补造数据、擅自修改模型结果。若曲线不符合常识，**先查数据和绘图逻辑，
> 不要直接修数据**。本次全部图件只做单位换算（kW↔kWh）与坐标轴范围选择，
> **未对任何数据做平滑、插值、删点或补造**。
>
> **已修正的口径陷阱**：`payload` 的 `plan_cost_yuan` / `adjusted_cost_yuan` 是**表1 模板行口径**，
> 而 `total_cost_yuan` 与三项之和是**自然日口径**，两者相差 **57.6203 元**（恰为一个午夜列）。
> 为避免混用，`_figdata/q3_daily_metrics.csv` 的费用列一律采用**自然日口径**
> （列名 `plan_cost_yuan_natural` / `adjust_cost_yuan_natural`），并额外保留模板行口径列供核表1。

## 三、论文可直接使用的图注

> 说明：下列图注已与成图逐项核对（数值、单位、口径均一致）。
> 图中**不重复大标题**，图名请用这里的图注（规范第十三节）。

**图 3-1a**　日内电价与净负荷形态。上图：电价（元/kWh）；下图：净负荷（MW，每 10 分钟），阴影为净负荷为负的**光伏富余**区间，标注点为全年最高电价时刻。数据为交付期 334 个自然日的逐小时合计与电价。

**图 3-1b**　光伏预报精度：双源组合对比。纵轴为白天（06:00–18:00）RMSE（kW）。0:00 发布时，仅用附件3 整点预报的单源方案为 543 kW，与近 10 日指数衰减均值组合后降至 355 kW（**−35%**）；6:00 与 12:00 发布的组合后 RMSE 分别为 284 与 188 kW。18:00 发布无标定值，故留空。

**图 3-2a**　各日合约量调整量。正值为上调、负值为下调（kWh）。全年累计上调 585,146.1293 kWh、下调 265,196.7037 kWh，**净上调 319,949 kWh**。

**图 3-2b**　指定日期计划购电量与最终合约量。(a) 电价（元/kWh）；(b) 2025-03-20；(c) 2025-09-23。实线为最终合约量、虚线为 0:00 计划量（kWh/10 分钟）。两线分离处即日内三次预报更新导致的调整。

**图 3-3a**　月度费用构成与月度弃电量。(a) 三项费用堆叠（万元）：计划购电费为主体，调整相关费用与紧急购电费为小项，最高月为 12 月（164.9）；(b) 月度弃电量（MWh），仅最高月 5 月用强调色标出（186.7）。两面板共用同一月份位置与左右边界，纵轴单位分别为「费用 / 万元」与「弃电量 / MWh」（1 MWh = 10³ kWh）。

**图 3-3b**　弃电量的日内分布。横轴为时刻（h），纵轴为弃电量（kWh）。**11:00–15:00 合计占全年弃电 90.3%**，成因是午间光伏富余且储电量已接近上限。

**图 3-4a**　四个典型日期的储电量轨迹（2×2 面板）。每面板一个日期（2025-03-20 / 06-21 / 09-23 / 12-21），四个面板使用**完全相同的 x 轴（0–24 h）与 y 轴（350–11400 kWh）**，可直接横向比较。绿色虚线为 1200 与 10800 kWh 的**运行边界**，两条线在四个面板中位置完全一致（同款线型与颜色）。四个日期的全部 144×4 个时段储电量均落在边界之内，且轨迹形态差异显著：06-21 与 09-23 分别在午后贴到 10800 上限，03-20 与 09-23 的谷值恰好触到 1200 下限，12-21 的日间回充最晚、日终储电量最高（均值 7904 kWh，明显高于其余三日约 7154–7200 kWh）。

**图 3-4b**　储电量分布与边界触及。横轴为储电量（kWh），纵轴为时段数（共 48,096 个 10 分钟时段）。**贴上限占 9.84%、贴下限占 1.18%**——分布明显偏向高段。

**图 3-4c**　充电量与放电量的分布。横轴为单时段充/放电量（kWh），纵轴为时段数；虚线为单时段功率上限 833.3333 kWh。充电 21,565 个时段、放电 22,092 个时段；打满上限的仅充电 859、放电 49 个时段。

**图 3-5a**　紧急购电量的日内分布。横轴为时刻（h），纵轴为紧急购电量（kWh）。**19:00–21:00 合计占全年紧急购电量 67.5%**——该时段电价最高、光伏已退出。

**图 3-5b**　紧急购电按电价档的分布。(a) 电量（kWh）；(b) 费用（元）。纵轴按四档电价分组，最高价位段（≥1.05 元/kWh）虽时段数不是最多，却贡献了主要费用。

**图 3-6**　八种预报发布组合的交付期总费用。横轴为总费用（元，自 13.0 百万元起）；灰色为基线"仅 0:00 发布"，蓝色为最优组合 `0+6+12+18`。虚线为基线水平。**全启用相对仅 0:00 发布节省 622,379 元（4.5149%）**。

**图 3-7a**　三种求解算法下的费用偏差。纵轴为主答案与备选算法的费用之差（元）。`highs-ds` 与主答案**逐位相同**（偏差 0）；`highs-ipm` 为 **−28.21 元（−0.0002%）**。年度费用**不依赖**求解器配置。

**图 3-7b**　终端储能水价 λ 的全年敏感性。横轴为 λ 相对基准（0.478 元/kWh）的倍数，纵轴为交付期总费用（万元）；虚线为主答案水平，阴影为**储能运行机制切换区间**。**0–3 倍内极差 97,158 元（0.7381%），且费用对 λ 非单调** ⇒ 不能说某个 λ 更优。

## 五、已知限制（论文中若引用相关图，需同时说明）

1. **图 3-1b 的 6:00 / 12:00 没有"单源 vs 组合"的成对数字**——`docs/q3_multistage_model.md` §5
   只给出了组合后的值（284、188 kW），单源值仅 0:00 有（543 kW）。图中未伪造单源值。
2. **图 3-2a / 3-2b 的横轴为"日期"，不是"连续小时"**——因数据为 334 个自然日，
   直接按日序号绘制，未做日内插值（规范：禁止无意平滑）。
3. **图 3-4c 的放电直方图在 430–470 kWh 区间有一个次峰**——这是真实分布特征
   （对应午后放电集中在中等功率），不是绘图伪影。
4. **图 3-4a 中 2025-03-20 与 2025-09-23 的谷值恰好等于 1200 kWh**——这是模型的最优结果
   （储能被用到运行下限），不是绘图或数据异常；06-21 与 09-23 的最高点恰好 10800 kWh 同理。
   图 3-4a 采用 **2×2 小面板**而非单图叠加，是为了让四条轨迹互不遮挡、
   并可借**统一坐标**直接横向对比；因此不再需要图例。
4. **图 3-6 的横轴自 13.0 百万元起（截断）**——八个组合费用差异仅 4.5%，
   全量刻度无法分辨；已在轴标题与图注中声明截断。纵轴方向为**横向条形**以容纳 8 个标签。
5. **图 3-7a 画的是"偏差"而非"绝对费用"**——两者仅差 28 元，绝对刻度下三根柱等高。
   纵轴为有数学意义的差值（基准 0 = 主答案），**不是截断坐标轴**。
