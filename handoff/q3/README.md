## 3. 复现

```powershell
cd handoff/q3/scripts
python gen_plot_data.py          # ① 生成 _figdata（只读仓库产物，约 10 秒）
cd ../figures
python figs_q3_paper.py          # ② 出图：内部先做 2,854 项数据审计，再画 14 个文件
cd ..
python make_album.py             # ③ 装册 -> 图集_第三问_论文版.pdf
```

依赖：`numpy`、`pandas`、`matplotlib`、`Pillow`、`openpyxl`（读附件用）。

**注意**：`gen_plot_data.py` **不重跑求解器**，只读 `zz/outputs/q3_multistage/` 的已交付产物；
若要重跑模型本身，见 `docs/q3_multistage_model.md` §9（约 370 秒/次）。

## 5. 四个必须同时说明的口径（论文下笔前必读）

1. **双时间框**：计划/调整购电用**模板行**（当日 00:10 → 次日 00:10，与附件5 逐列对应）；
   执行、储电量、紧急购电与总费用用**自然日**（00:00–24:00，跨行重组）。
   **两者不可跨表相加**——计划量差 134.7528 kWh、计划费差 57.6203 元（恰为一个午夜列）。
2. **模型定位**：本模型是**滚动两阶段近似**，`strict_multistage_optimal = false`。
   可写"滚动随机规划近似"，**不能写"多阶段随机最优"**。
3. **不做"唯一最优策略"的表述**：LP 普遍退化（46.9% 的解向量不同），
   年度**费用**稳定，但逐时段充放电安排只是**最优解之一**。实时层还是**贪心规则**，
   不是滚动 LP 最优，**不得**把"无同时充放电"当作经济最优的证明。
4. **已关闭的证据缺口**（可正面引用）：
   预报组合对照（题面最后一问，全启用省 622,378.8759 元 = 4.5149%）；
   求解器配置敏感性（最坏差 28.21 元 = 0.0002%，故 13,162,682.89 元可称"该模型的最优费用"）；
   独立复算（不 import 模型，偏差 ≤ 1e-9）；λ 全年敏感性（极差 0.7381%，**非单调**，有机制切换）。
   **仍须保留**：复算不重解 LP，"记录解是最优解"未被独立复核；
   预测子模型、SAA 情景生成、终端价值 λ、锁定区间规则都仍是**建模选择**。

## 6. 尚存限制

1. 情景数 `K` 未扫描（仅 30）。
2. λ 变化时八组合的价值是否改变未测（现有组合对照结论只在 λ=0.478 下成立）。
3. 实时层为贪心规则，非滚动 LP 最优。
4. 附件未提供负荷预报，日内负荷预测沿用计划日前历史轮廓（只做水平修正）。
5. 组合权重 `WCOMB` 自述"已标定"，无独立标定过程文档。
