## 零、问题三要证明什么

**研究目标**：在每天 0:00、6:00、12:00、18:00 可获得未来 24 小时整点光伏预报的条件下，
制定"计划购电 → 日内三次调整 → 实时紧急购电"的分层策略，使全年购电费用最小。

**必须靠图证明的结论**（其余用表格）：

| # | 结论 | 为什么必须用图 |
|---|---|---|
| C1 | 预报组合把白天 RMSE 从 543 降到 355 kW | 需要展示"双源近似不相关"的降误差效果 |
| C2 | 三次预报更新产生了大量合约量调整，且调整集中在特定时段 | 需要展示调整的**时序结构** |
| C3 | 储能被充分使用但运行在边界附近（贴上界 9.84%） | 需要展示**分布**与**轨迹** |
| C4 | 紧急购电极少（0.1918%）且高度集中在 19:00–21:00 | 需要展示**集中度** |
| C5 | 三个预报时刻**都值得引入**（全启用省 4.5149%） | 需要展示**八组合比较** |
| C6 | 年度费用**不依赖**求解器配置与终端水价 | 需要展示**稳定性/敏感性** |

**用表格而非图**：表1/表2/表3（四个指定日期）、三项费用拆分、月度明细、Shapley 精确值。

**不值得画的过程数据**：逐时段原始 x/q/c/g/z/w 全量序列（只画代表性切片）、
1,460 个阶段 LP 的规模统计。

**去重**：SOC 轨迹（C3 轨迹面）与 SOC 分布（C3 分布面）结论不同，保留；
"调整量"的日度视角（图3a）与组合视角（图6）结论不同，保留。

## 二、逐图设计表

### 图 3-1a 日内电价与净负荷形态

- **图号/文件名**：图 3-1a；`figures/fig3_1a_system_profile.png|svg|pdf`
- **用途**：交代数据层——峰谷价差与午间光伏富余同时存在，这是储能套利与弃电的根源。
- **数据来源**：`_figdata/q3_hourly_profile.csv`（`hour`、`price_yuan_per_kwh`、`net_load_kwh`）
- **横轴**：时刻 / h（0–24，刻度 0/4/8/12/16/20/24）
- **纵轴**：上＝电价 / (元/kWh)；下＝净负荷 / kWh（每 10 分钟）
- **图型**：上下双面板折线（**不用 twinx**）
- **需要强调**：峰价时段（19–21 时）；净负荷负值（光伏富余）区
- **需要弱化**：其余时段
- **基准线**：净负荷 ＝ 0（数学意义：光伏富余分界）
- **面积填充**：仅填净负荷 < 0 的区域，`alpha=0.12`，有明确含义（光伏富余）
- **图内标注**：≤2 处（"光伏富余"、"峰价"）
- **推荐图注**：图 3-1a　日内电价与净负荷形态（全年 334 天逐时段均值；阴影为光伏富余区间）
- **论文位置**：第三问"数据预处理"末段

### 图 3-1b 双源组合预报的降误差效果

- **图号/文件名**：图 3-1b；`figures/fig3_1b_forecast_accuracy.*`
- **用途**：证明"附件3 整点预报 + 近 10 日衰减均值"两源组合确实降低误差。
- **核心问题**：组合预报比单源好多少？各发布时刻差异如何？
- **数据来源**：`docs/q3_multistage_model.md` §5 的标定值（0:00 543→355 kW；6:00→284；12:00→188）
- **横轴**：发布时刻（0:00 / 6:00 / 12:00 / 18:00）
- **纵轴**：白天 RMSE / kW
- **图型**：分组柱（仅 0:00 有成对数字，其余为训练值）
- **需要强调**：0:00 那一组（降幅最大、成对可证）
- **需要弱化**：其余三个时刻
- **基准线**：无
- **⚠️ 数据限制**：只有 0:00 存在"单源 vs 组合"成对数字；其余时刻只有组合后的单值。
  图中把 0:00 画为成对柱，其余画为单柱并在图注声明——**不得伪造单源值**。
- **推荐图注**：图 3-1b　光伏预报精度：0:00 发布时双源组合使白天 RMSE 由 543 kW 降至 355 kW
- **论文位置**：第三问"预测子模型"

## 三、数据审计（绘图前必做）

脚本 `figures/figs_q3_paper.py` 内置 `audit()`，在绘图前逐项断言：

| 审计项 | 断言 |
|---|---|
| 日度行数 | 334 天，日期升序无重复 |
| 小时行数 | 24 行，`hour` = 0..23 升序 |
| 目标日明细 | 4 日 × 144 段，`t_template` 0..143 升序 |
| 电价向量 | 24 点取自自然日向量，首段 = 上一原始行末列 |
| 单位一致 | 电量列全为 kWh、价格列全为 元/kWh |
| 无 NaN | 所有参与绘图的列无缺失 |
| 合计一致 | 日度 `total_cost_yuan` 之和 = `q3_meta.json` 的 `totals.total_cost_yuan`（1e-6） |
| 三项费用一致 | 计划+调整+紧急 = 总费用（按日逐条） |
| 时间轴 | 自然日 0–24 无重复端点；**不产生 24:00 异常竖线**（末段为 23:50–24:00） |
| 合计与分项 | 月度合计 = 全期合计 |
| 百分比合理 | 贴边占比、紧急占比均在 [0,100] |

**严禁**：为让图好看而修改任何数据。
